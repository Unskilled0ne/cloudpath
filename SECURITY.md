# Security Policy

## Educational & Research Scope
This repository contains cloud security auditing and privilege escalation analysis tooling. It is designed to assist cloud administrators and security engineers in identifying and remediating identity posture risks within authorized environments.

## Reporting Vulnerabilities
If you discover a security issue or defect within CloudPath, please disclose responsibly:
- **Do not** disclose vulnerabilities via public GitHub issues.
- Contact the maintainer directly at: **btsiamouras@gmail.com** or via [LinkedIn](https://www.linkedin.com/in/vasilis-tsiamouras/).
- Provide reproduction steps and technical details to facilitate prompt remediation.
